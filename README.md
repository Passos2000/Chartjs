# Chartjs
Dashboard com gráficos de linhas e barras de temperatura e umidade, feito com HTML, CSS, JavaScript e Chart.js

# Dashboard de Temperatura e Umidade

Painel com dois gráficos feitos com **Chart.js**, em tema escuro:

- **Gráfico de linhas:** temperatura e umidade ao longo do dia (12:00 às 17:00)
- **Gráfico de barras:** temperatura média e umidade média de janeiro a junho

## Tecnologias

- HTML
- CSS
- JavaScript
- [Chart.js](https://www.chartjs.org/docs/latest/)

## Estrutura do projeto

```
├── index.html   # estrutura da página
├── style.css    # estilo (fundo preto)
└── script.js    # dados e configuração dos gráficos
```

## Como executar

1. Baixe ou clone este repositório:
```bash
   git clone https://github.com/Passos2000/dashboard-chartjs.git
```
2. Abra a pasta do projeto.
3. Dê dois cliques no arquivo `index.html` para abrir no navegador.

> É necessário ter conexão com a internet, pois o Chart.js é carregado por CDN.
